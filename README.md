# Notebook App

Кроссплатформенное приложение для личных и совместных заметок, задач, вопросов
и желаний. Этот репозиторий — раздача готовых сборок; исходный код и разработка
ведутся отдельно.

**Текущая версия — 1.0.7** (список изменений по версиям — в [`history/`](history/)).

## Какая стояла задача

Один инструмент, который закрывает повседневную организацию дел и для себя, и
для семьи/команды:

- держать в одном месте **заметки, задачи (с подзадачами), вопросы и желания**;
- иметь доступ с телефона и компьютера с синхронизацией через сервер;
- не зависеть от магазинов приложений и подписок, данные — на своём сервере;
- уметь работать **совместно**: общие списки, к которым есть доступ у всех
  участников группы.

## Как реализовано

- **Бэкенд:** NestJS + Prisma + PostgreSQL. JWT-авторизация, подтверждение
  email, двухфакторная аутентификация (TOTP), рассылка писем по SMTP.
- **Клиент:** Flutter — единая кодовая база на Android, Windows и Linux.
  Разделы: Заметки (избранное, поиск), Задачи (приоритет, срок, чек-лист
  подзадач), Вопросы (фильтр «с ответом / без ответа»), Желания (статусы
  активно / исполнено / отменено). Сквозной серверный поиск по всем разделам.
- **Группы:** создание группы, приглашение участников по email (ссылка +
  подтверждение в приложении), роли администратора и участника, признак
  «общее / личное» у каждой записи, бан участника на срок. Переключатель
  контекста «Личное / Группа» вверху экрана.
- **Android дополнительно:** вход по отпечатку пальца, встроенный механизм
  обновления (скачивает и ставит новый APK поверх текущего).
- **Desktop → телефон:** экран «Установить на телефон» с QR-кодом и прямой
  ссылкой на актуальный `.apk` — приложение на компьютере само раздаёт сборку
  на смартфон.

## Чем упрощает жизнь

**Лично:**

- всё — заметки, дела, открытые вопросы, «хотелки» — в одном приложении и
  синхронизировано между устройствами;
- быстрый захват мысли или задачи; задачи можно дробить на подзадачи и видеть
  прогресс;
- поиск сразу по всем разделам;
- вход по отпечатку и 2FA — доступ защищён, данные лежат на вашем сервере,
  без подписок.

**В группе (семья, команда, проект):**

- общие списки покупок, задач и заметок: то, что помечено «общим», видят и
  редактируют все участники, удаляет автор или администратор;
- приглашение новых участников по email — если человек ещё не зарегистрирован,
  он вступает в группу автоматически при регистрации под этим адресом;
- личное и общее не смешиваются: одним переключателем выбираете, в каком
  контексте работаете;
- администратор поддерживает порядок в группе — может временно ограничить
  доступ участнику или исключить его.
