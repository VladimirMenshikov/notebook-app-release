# Установка Notebook App

Инструкция для конечного пользователя — как поставить готовое приложение.
Для сборки из исходного кода см. `INSTALLATION.md` в корне репозитория.

## Android

1. Скачайте `apk/notebook-app_X.X.X.apk` (актуальный файл — с самым большим
   номером версии в имени; более старые версии можно удалить).
2. Скопируйте файл на телефон (USB, облако, Telegram себе и т.п.) и откройте
   его через файловый менеджер.
3. При первой установке система спросит разрешение на «Установку из
   неизвестных источников» — разрешите его для приложения, через которое
   открываете файл (Файлы / Telegram / браузер).
4. Нажмите **Установить**.

Приложение сразу подключается к рабочему серверу — ничего донастраивать
не нужно.

### Дальнейшие обновления

После первой установки отдельно скачивать новые версии не требуется —
приложение само проверяет обновления при каждом запуске и предлагает
установить новую версию поверх текущей (данные и вход в аккаунт
сохраняются). Проверить вручную можно в **Настройки → О приложении →
Проверить обновления**.

## Linux

1. Скачайте `deb/notebook-app_X.X.X_amd64.deb` (актуальная версия).
2. Установите:
   ```bash
   sudo dpkg -i notebook-app_X.X.X_amd64.deb
   ```
3. Если появится ошибка о неудовлетворённых зависимостях:
   ```bash
   sudo apt install -f
   ```

Приложение появится в меню приложений как **Notebook App**, либо
запускается из терминала командой `notebook-app`.

### Обновление версии

Повторная установка новой `.deb`-версии той же командой (`sudo dpkg -i ...`)
обновляет приложение на месте — переустанавливать/удалять предыдущую
версию не нужно.

### Удаление

```bash
sudo dpkg -r notebook-app
```

## Windows

Windows-версия распространяется как **портативное приложение** — папка с
`notebook_app.exe` и сопутствующими файлами, установка не требуется.

1. Скачайте `win/NotebookApp-X.X.X-windows-x64.zip` (актуальная версия).
2. Распакуйте архив в любую папку (например `C:\Program Files\NotebookApp`
   или на рабочий стол).
3. Запустите `notebook_app.exe`.

> Приложение работает только целиком: `.exe` рядом с `flutter_windows.dll`,
> прочими `*.dll` и папкой `data\`. Не переносите один `.exe` отдельно.

Приложение сразу подключается к рабочему серверу — донастройка не нужна.
При первом запуске Windows SmartScreen может предупредить о неизвестном
издателе (приложение не подписано) — «Подробнее» → «Выполнить в любом случае».

### Обновление версии

Скачайте новый архив и замените им содержимое папки. Данные и вход в аккаунт
хранятся в профиле пользователя и при обновлении сохраняются.

### Сборка из исходников

В архиве уже готовый `.exe`. Если нужно собрать самому — в каталоге `win/`
лежат исходники и инструкция `win/BUILD_WINDOWS.md`.
